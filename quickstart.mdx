# Quickstart Guide

Deploy production-ready Google Cloud infrastructure for Agentic AI solutions in under 30 minutes!

<Callout type="info" title="Estimated Time: 20-30 minutes">
This guide walks you through a complete infrastructure deployment. Actual deployment to GCP takes 15-20 minutes.
</Callout>

## Step 1: Clone the Repository

```bash
git clone https://github.com/your-org/gcp-iac-repo.git
cd gcp-iac-repo
```

## Step 2: Authenticate with Google Cloud

<Tabs>
  <Tab title="Interactive Login">
    ```bash
    # Login to Google Cloud
    gcloud auth login
    ```
    Follow the browser prompt to authenticate.
  </Tab>
  <Tab title="Set Project">
    ```bash
    # Set your active project
    gcloud config set project YOUR_PROJECT_ID
    
    # Verify the project
    gcloud config list
    ```
  </Tab>
  <Tab title="Enable APIs">
    ```bash
    # Enable required APIs
    gcloud services enable compute.googleapis.com
    gcloud services enable storage.googleapis.com
    gcloud services enable iam.googleapis.com
    gcloud services enable cloudresourcemanager.googleapis.com
    ```
  </Tab>
</Tabs>

## Step 3: Configure Terraform Variables

Create a `terraform.tfvars` file in the root directory:

```hcl
# Core Configuration
project_id     = "your-gcp-project-id"
region         = "us-central1"
zone           = "us-central1-a"
environment    = "dev"

# Network Configuration
network_name   = "agentic-ai-network"
subnet_name    = "agentic-ai-subnet"

# Optional: Customize these values
enable_monitoring = true
enable_logging    = true
```

<Callout type="info" title="Configuration Help">
See the [Configuration Guide](/crewai/gcp-setup#configuration-guide) for detailed explanations of all variables.
</Callout>

## Step 4: Initialize Terraform

<Steps>
  <Step title="Navigate to Terraform Directory">
    ```bash
    cd terraform
    ```
  </Step>
  <Step title="Initialize Terraform">
    ```bash
    terraform init
    ```
    This downloads the required Terraform providers and modules.
  </Step>
  <Step title="Validate Configuration">
    ```bash
    terraform validate
    ```
    Ensures your Terraform code is syntactically correct.
  </Step>
</Steps>

<Callout type="success" title="Initialization Complete">
You're ready to preview the infrastructure deployment!
</Callout>

## Step 5: Review the Deployment Plan

```bash
terraform plan
```

This command shows you exactly what Terraform will create without making any changes. You should see output like:

```
Plan: 15 to add, 0 to change, 0 to destroy

...resources to be created...
```

<Callout type="info" title="Understanding the Plan">
  - **to add**: New resources that will be created
  - **to change**: Existing resources that will be modified
  - **to destroy**: Resources that will be deleted
  
  Review the plan carefully before proceeding!
</Callout>

## Step 6: Deploy the Infrastructure

```bash
terraform apply
```

When prompted, review the plan one more time and type `yes` to confirm:

```
Do you want to perform these actions?
  Terraform will perform the actions described above.
  Only 'yes' will be accepted to approve.

  Enter a value: yes
```

<Callout type="warning" title="Deployment in Progress">
This will create actual resources in your GCP project. Deployment typically takes **15-20 minutes**. You'll see progress updates in your terminal as each resource is created.
</Callout>

## Step 7: Verify Deployment

After deployment completes successfully, verify your infrastructure:

<Tabs>
  <Tab title="List Created Resources">
    ```bash
    # List your networks
    gcloud compute networks list
    
    # List instances
    gcloud compute instances list
    
    # List storage buckets
    gcloud storage buckets list
    ```
  </Tab>
  <Tab title="View Terraform Outputs">
    ```bash
    # Display all outputs
    terraform output
    
    # Get specific output
    terraform output network_id
    terraform output subnet_id
    ```
  </Tab>
  <Tab title="Test Connectivity">
    ```bash
    # For compute instances
    gcloud compute ssh INSTANCE_NAME --zone=ZONE
    
    # Check security groups
    gcloud compute security-policies list
    ```
  </Tab>
</Tabs>

Now that your infrastructure is deployed, you can:

</CardGroup>

## Common Next Steps

### 1. Deploy Application Services

Once your foundation is ready:

```bash
cd terraform/modules/app-services
terraform init
terraform apply
```

<Callout type="info" title="What Gets Deployed">
Application-specific services, databases, caching layers, and load balancers.
</Callout>

### 2. Configure CI/CD

Set up continuous deployment:

```bash
cd .github/workflows
# Review and customize GitHub Actions workflows
git add .
git commit -m "Configure CI/CD for project"
git push
```

### 3. Set Up Monitoring

Configure custom dashboards and alerts:

<Tabs>
  <Tab title="Using Terraform">
    ```bash
    cd terraform/modules/monitoring
    terraform apply
    ```
  </Tab>
  <Tab title="Using Cloud Console">
    1. Go to **Monitoring** > **Dashboards**
    2. Click **Create Dashboard**
    3. Add metrics and charts for your resources
  </Tab>
</Tabs>

### 4. Configure Logging

Enable comprehensive logging across your infrastructure:

```bash
gcloud logging sinks create cloud-storage-sink \
  storage.googleapis.com/your-logging-bucket \
  --log-filter='resource.type="gce_instance"'
```

## Troubleshooting

### Terraform Init Fails

<Callout type="error" title="Error: Failed to download module">
  ```bash
  rm -rf .terraform
  terraform init
  ```
  Clear the Terraform cache and try again.
</Callout>

### Authentication Errors

<Callout type="error" title="Error: Google Cloud credentials not found">
  ```bash
  gcloud auth application-default login
  ```
  Re-authenticate with GCP.
</Callout>

### API Not Enabled

<Callout type="error" title="Error: Service has not been used in project">
  ```bash
  gcloud services enable <service-name>
  ```
  Enable the required GCP service manually.
</Callout>

For more troubleshooting, see the [Full Troubleshooting Guide](/crewai/gcp-setup#troubleshooting).

## Troubleshooting

### Authentication Errors

If you encounter authentication errors:

```bash
# Re-authenticate
gcloud auth application-default login

# Verify credentials
gcloud auth list
```

### Permission Errors

Ensure your account has the required IAM roles:

```bash
# Check your roles
gcloud projects get-iam-policy YOUR_PROJECT_ID --flatten="bindings[].members" --filter="bindings.members:user:YOUR_EMAIL"
```

### Terraform State Issues

If you encounter state lock issues:

```bash
# Force unlock (use with caution)
terraform force-unlock LOCK_ID
```

## Clean Up (Development Only)

To remove all created resources:

```bash
terraform destroy
```

**Warning**: This will delete all infrastructure. Only use this in development environments.
